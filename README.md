# SmartReference 智能引用

在 VS Code 底部面板集中查看符号引用，适合批量筛选 Unity/C# 等项目中的调用位置。

## 使用

1. 按 F5 启动扩展开发宿主，并打开需要分析的代码项目。
2. 将光标放在符号上，右键选择 **查找智能引用**，或按 **Shift+F12**（Windows 和 macOS 相同）。
3. 底部打开 **智能引用**，也可以在命令面板执行 **SmartReference: 显示智能引用窗口**。

需要快速查看匹配代码时，选中单行文本或把光标放到单词上，右键选择 **快速浏览匹配**，命令面板中也提供同名命令。窗口工具栏支持在 **精确引用 / 快速文本匹配** 间切换，模式会在当前工作区保存。

**精确引用**复用当前语言的引用提供器。分析 C# 时，需要启用 C# 扩展并等待项目加载，查询覆盖范围由语言服务决定。**快速文本匹配**直接扫描工作区源码，包含同名符号、注释和字符串中的字面匹配，不依赖 C# 语言服务或解决方案加载，不补充包含成员和类型。

快速模式边扫描边追加结果；同一行的多处命中合并为一行并全部高亮，点击跳到首次命中。已经打开的文件使用未保存内容，其他文件直接从文件系统读取，扫描过程不会批量打开编辑器文档。取消会终止文件枚举及后续读取分配，并保留已显示的匹配行。

## 快速文本匹配设置

默认扫描常见源码和配置文件，跳过 Unity 的 Library、Temp、Logs 以及常见构建、依赖和版本库目录。支持多个工作区文件夹，合并布尔型 `files.exclude` 和 `search.exclude`，带 `when` 条件的排除项不作无条件排除。

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| `smart-reference.quickSearch.include` | 常见源码和配置文件后缀 | 设置扫描文件的 Glob，例如 `**/*.cs` |
| `smart-reference.quickSearch.exclude` | 缓存、构建及依赖目录 | 设置额外排除 Glob |
| `smart-reference.quickSearch.matchCase` | `true` | 是否区分大小写 |
| `smart-reference.quickSearch.wholeWord` | `false` | 是否只匹配完整标识符 |
| `smart-reference.quickSearch.maxResults` | `5000` | 最多显示的匹配行数 |
| `smart-reference.quickSearch.maxFiles` | `20000` | 最多扫描的文件数 |
| `smart-reference.quickSearch.maxFileSizeMB` | `2` | 单个文件大小上限 |

达到上限或跳过文件时会显示提示。快速模式遵循文件编码设置，并识别 UTF-8/UTF-16 BOM；编码无效或二进制内容会跳过。工作区的 gitignore 规则不保证与原生全文搜索完全一致，请通过排除设置控制扫描范围。

## 窗口交互

- **紧凑列表**：默认结果行高为 22px，依次展示行、代码、文件、工作区、包含成员和包含类型。
- **列宽调整**：左右拖动表头分隔线；双击恢复该列默认宽度。分隔线获得焦点后，左右键调整 10px，Shift+左右键调整 30px，Home 恢复默认。
- **列显示**：点击 **显示列** 或右键表头，勾选需要显示的列；至少保留一列。支持恢复默认列和列宽。
- **状态保留**：列宽、列显示状态、筛选内容、分组、换行、预览开关和滚动位置会随视图状态保存。升级后的列宽按列名称匹配，兼容旧版保存的列宽。
- **完整代码**：读取包含未保存修改的完整物理代码行；结果中去掉前导空格和制表符并左对齐，保留引用高亮与真实跳转位置。长行可启用 **换行** 查看全部内容。
- **语法颜色**：结果代码和上下文预览支持本地语法高亮，区分关键字、内置类型、字符串、数字、注释和声明名称，并叠加引用命中底色；仅处理可见行并缓存结果，不增加语言服务请求。
- **隔行底色**：默认开启，工具栏可切换并保存；按当前显示的引用行交替着色，分组标题不计入，滚动时颜色保持稳定。
- **筛选和分组**：按代码、文件名、路径、工作区、成员和类型筛选，支持按文件、按工作区分组或平铺。
- **跳转**：单击在编辑器中预览并保持列表焦点；双击或 Enter 正式打开文件；上下键、Home 和 End 选择引用。
- **上下文**：鼠标悬停不弹出代码预览；启用 **预览** 后，选中引用可在右侧查看原始上下文，窄窗口中预览移到底部。
- **查询控制**：支持重新查询、取消和清空；连续查询时忽略旧请求的迟到结果。
- **大结果集**：仅渲染可见区域附近的结果行，避免为全部引用创建页面元素。

窗口注册在 VS Code 的 Panel 区域，与终端、输出和问题并列。用户可以通过 VS Code 的布局操作调整区域位置和高度，扩展沿用保存的布局。

## 数据边界

- 工作区表示工作区文件夹，不等同于真实的 .csproj 项目归属。
- 包含成员和类型由文档符号提供器补充，不支持时留空；不推测读写类别。
- 语法颜色使用本地 highlight.js 规则和适配亮暗主题的配色，属于代码片段着色，不等同于编辑器的语义高亮；跨行语法可能存在差异。不支持的语言和超长代码行保留普通文本及引用命中高亮。
- 隐藏视图可保留本次会话结果；重启扩展宿主后需要重新执行查询。
- 文档修改、文件重命名或删除后会提示结果可能过期；跳转和预览时校验文档内容，阻止使用已经失效的位置。
- 原始查询文件被修改时，精确引用需要先将光标放回符号并执行查找；快速模式可以直接按原有文本重新搜索。
- 不替换原生 Peek References 或 CodeLens 的引用入口。

## 本地安装与更新

从 0.0.2 开始，扩展 ID 为 `zhanghongfei.smart-reference`。如果已经安装使用占位 publisher 的旧版 `your-publisher-id.smart-reference`，需要先卸载旧版，避免两个扩展同时注册相同的命令和视图：

```powershell
code --uninstall-extension your-publisher-id.smart-reference
code --install-extension .\smart-reference-0.0.3.vsix --force
```

在 VSIX 所在目录执行安装命令，完成后在 VS Code 中执行 **Developer: Reload Window**。后续保持 `zhanghongfei.smart-reference` 这个 ID，直接安装更高版本的 VSIX 即可更新，无需再次卸载。这里只设置本地扩展清单中的 publisher，不会创建 Marketplace 发布者账号或发布到 Marketplace。

```sh
npm run compile
npm run lint
node --check media/referenceView.js
```

F5 后检查真实语言服务的引用数量、列宽拖动与恢复、长代码换行、分组筛选、键盘导航、上下文预览，以及修改和重命名文件后的过期提示。
